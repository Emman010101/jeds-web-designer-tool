How this version works

The Worker is no longer required. The app tries direct browser requests and reports access failures instead of hiding them.

For sitemap cleanup, you can always paste or upload the XML file. Cleanup and XML validation run locally in your browser.
If direct page requests fail with CORS or a security challenge, the browser cannot read those pages. The app will show them as blocked rather than falsely reporting “no matches.”
